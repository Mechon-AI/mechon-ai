Modular Engineering Architecture

Everything needed to engineer LLM datasets.

From unstructured raw documents to pre-flight certified multi-turn dialogue corpora.

Story Architect

A dedicated Scene View for interactive conversation engineering. Features an autonomous dual-agent loop (Planning + Evaluation), in-place turn editing, and automatic downstream revision invalidation.

Scene Viewport • Dual Agents →

SFT Studio & Multilingual Pipeline

Multi-turn conversation authoring with real-time multilingual alignment. Supports dynamic language pairs, selective turn translations, manual edit preservation, and retry workflows.

Direct Editor • Translation Pipeline →

DPO Studio (Direct Preference)

Curate pairwise candidate completions across models and temperatures. Formatted directly for Hugging Face TRL (prompt, chosen, rejected).

HF TRL Compatible • Pairwise Review →

Training Readiness Certification

8-dimension pre-flight quality audit engine certifying datasets into READY or BLOCKED before you spend GPU compute.

8-Dimension Audit • Pre-Flight Gate →

Fine-Tuning Engineering Suite

Token estimation histograms, exact & semantic deduplication, persona conflict audits, chat template syntax validation (Jinja2/Llama-3/ChatML), and deterministic zero-leakage partition splits.

Analytics • Dedup • Chat Templates →

Local-First & Zero Telemetry

All data persists locally in high-performance SQLite WAL. API credentials securely stored via Linux Freedesktop Secret Service (KDE Wallet) with an encrypted fallback vault. No data ever leaves your machine.

KDE Wallet • SQLite WAL • 100% Private →

Build From Source

Clone the repository and run with native Rust Cargo & Vite developer harness.

git clone https://github.com/Mechon-AI/mechon-ai.git
cd mechon-ai/frontend && npm i && npm run build
cd ../src-tauri && cargo run
